## 🌱 我如何看待 AI Coding

- **目标先于路线。** 先说明为什么要做、做到什么程度,而不是先指定答案。
- **探索必须守界。** 自主选择方法,不等于自行获得新的权限、预算或发布授权。
- **失败也是证据。** 保留无法复现、没有通过和证据不足的结果,不把工程活动当作能力增长。

**"生命会自己寻求出路"不是放任 AI 一直运行,而是允许它改变道路,也允许它及时停止。**
