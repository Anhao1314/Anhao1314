## 🚀 Currently Building

### [FlowCredit](https://github.com/Anhao1314/flowcredit)

> **Risk Intelligence Infrastructure for the AI-Native Economy**

FlowCredit is an evidence-aware counterparty risk intelligence system for AI-native businesses, agents, API and compute providers, and compute-intensive operators. It turns structured operational evidence into deterministic, machine-readable risk signals and prioritized actions.

**Evidence → Risk → Action**

- Deterministic risk engine with authoritative TAI, CCI, risk grade, and review status
- Evidence readiness, field-level coverage, provenance, and required actions
- Versioned Public API with JSON Schema validation and reproducible fingerprints
- Bearer authentication, idempotency, rate limiting, structured errors, and Docker deployment
- Public HTTPS External Alpha `v0.1.1`
- Finch Direct API contract and technical evaluation package ready; not submitted, approved, or published by Finch

**Role:** Founder / Product & Tech Lead

**Stack:** JavaScript · Node.js · JSON Schema / Ajv · Docker

→ [Explore FlowCredit](https://github.com/Anhao1314/flowcredit) · [Check the public service](https://flowcredit-api.onrender.com/health)

## Selected Work

### 🦾 [go2w-MoRA-navigation](https://github.com/Anhao1314/go2w-MoRA-navigation)

A reproducible, MuJoCo-based Unitree Go2w research portfolio for hierarchical navigation: rule-based task decisions, a high-level PPO policy, and low-level lookahead/differential control. Results are explicitly scoped to simulation and the repository's evaluation suite—not real-robot deployment or open-world generalization.
